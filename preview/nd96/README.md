# مقترح هوية اليوم الوطني السعودي الـ96 — «عزّنا بطبعنا»

معاينة تصميمية لمنيو الآيباد (index.html) بمناسبة اليوم الوطني الـ96 — الأربعاء ٢٣ سبتمبر ٢٠٢٦.

> ⚠️ **لم يُطبَّق أي تغيير على المنيو الفعلي.** هذا المجلد معاينة فقط بانتظار الموافقة.

## الملفات
| الملف | الوصف |
|---|---|
| `nd96-preview.png` | الشكل المقترح للشاشة كاملة (2000×1200) |
| `nd96-board.png` | لوحة الهوية: الألوان + العناصر + الضوابط + مقارنة قبل/بعد |
| `current.png` | لقطة المنيو الحالي (مرجع) |
| `nd96-theme.css` | طبقة التصميم الموسمية — تعمل عند إضافة `class="nd96"` على `<body>` |
| `nd96-inject.js` | عناصر اليوم الوطني (شريط السدو، وسم الشعار، شريط التهنئة، الشريحة الوطنية) |
| `board.html` | مصدر لوحة الهوية |

## المرجع البصري
- الشعار الرسمي لعام 2026 (اليوم الوطني 96): **«عزّنا بطبعنا»** — الهيئة العامة للترفيه.
- ست قيم/طباع: الشجاعة · الهمّة · الأصالة · الجود · الكرم · الرؤية.
- الأخضر السعودي `#006C35` أساس الهوية، مع لمسات ذهبية ونقوش مستلهمة من السدو.
- الخط الرسمي للهوية: «الخط السعودي» — وملفات الهوية الرسمية على `gea.gov.sa/nd`.

## مبدأ الدمج
٧٠٪ هوية ديو برجر (أسود `#070707` + أحمر `#BE1E2D`) + ٣٠٪ لمسة وطنية (أخضر + ذهبي).
الأحمر يبقى لون الأسعار والتصنيف النشط وشعار المطعم.

## عند الاعتماد
1. نقل `nd96-theme.css` إلى `css/` و`nd96-inject.js` إلى `js/` وربطهما في `index.html`.
2. إضافة مفتاح تشغيل/إيقاف في لوحة الكاشير + تفعيل تلقائي بالتاريخ (١٥–٢٥ سبتمبر).
3. استبدال رمز السعف والسيفين المبدئي بملفات الهوية الرسمية.
